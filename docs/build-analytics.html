    How these numbers were measured

    • Claude figures come from the Claude Code session logs for this project, covering the main checkout, worktrees, subagents and headless review runs. Each API response is counted once.
    • Codex figures come from Codex's session logs for runs whose working folder was this project.
    • Agent-hours add up every session's active time, so two agents working at once count twice. Wall-clock hours count any time at least one agent was working. A session counts as active until it has been quiet for 5 minutes.
    • Results were grouped from the developer's prompts by a fresh Claude session, then checked by hand. It's a judgement, not a measurement.
    • API prices are list prices on 14 Nov 2026. Claude Opus 5.5 costs US$4 per million input tokens, $20 per million output, $0.20 for cache reads, and $5 or $8 for cache writes to the 5-minute or 1-hour cache. GPT-6.1 Sol costs $2 per million input tokens, $0.10 cached and $10 output.
