# PDSA retro
1. **Plan:** find the original aims, predictions, timeline and definition of done. If there were none, reconstruct them with the user.
2. **Do:** measure from records, not memory: the user's time from prompt timestamps, agent time, tokens and cost by model, each result asked for with its prompts and outcome, code size over time, and real usage.
3. **Study:** a table of plan, result and verdict. Where the time went and what it bought. What worked and what cost most, with numbers. Get a second opinion from another model given the same facts, not your conclusions.
4. **Ask** the user what records can't show: the real purpose, how it went, what drained them. Revise.
5. **Act:** adopt, adapt, abandon. Turn repeatable lessons into skills.
6. Deliver a private page readable on a phone.
